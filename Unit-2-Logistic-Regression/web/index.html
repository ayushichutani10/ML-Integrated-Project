Customer Churn Prediction

Batch 6 · Logistic Regression · end-to-end ML project walkthrough

Project Overview

Goal: predict whether a customer will leave a service (binary classification).

How the project works

1
Load & clean – read the CSV, fix blank TotalCharges, drop customerID, encode the target. (Data tab)
2
Explore – see which customer groups churn most. (EDA tab)
3
Preprocess & split – scale numbers, one-hot encode categories, stratified 80/20 split. (Training tab)
4
Train – Logistic Regression tuned by 5-fold cross-validation; Random Forest for comparison. (Training tab)
5
Evaluate & interpret – precision, recall, F1, ROC-AUC, coefficients. (Results tab)
6
Predict – enter a customer and get a churn probability with reasons. (Try it tab)

Preprocessing & Training


Everything runs inside one scikit-learn Pipeline, so test data never leaks into training.




Pipeline

Numeric columns → StandardScaler  |  Categorical columns → OneHotEncoder → LogisticRegression(class_weight="balanced")

class_weight="balanced" compensates for churners being the minority. C is chosen with GridSearchCV (5-fold, scored on ROC-AUC).
